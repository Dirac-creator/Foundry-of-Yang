# 工艺模型接口约定（设计稿，尚未实现）

每种工艺提供独立的 predict、recommend、calibrate 能力。第一阶段优先实现 predict；模型不具备某能力时明确报“不支持”，不能返回虚构成功结果。

## predict

输入：样品 ID、版图版本、前序状态（材料、厚度、几何等）、候选参数（显式单位）、设备与配方版本、输入测量 ID。

输出：预测量（显式单位）、更新后的状态、不确定性或未评估说明、适用范围及超范围标志。每次运行保存 run_id、模型名称与版本、代码提交 SHA、输入数据 SHA-256、参数快照、运行时间；随机模型另存随机种子。

初期用 JSON 可序列化对象交换；材料与几何状态的具体 Schema 在首个模型实现时评审，不把目前的通用测量结构当作完整物理状态。

## recommend

输入：目标量、可调参数范围、设备约束、样品状态及指定模型版本。
输出：候选参数、预测目标值、不确定性与约束满足情况。建议由研究者审核后决定是否执行。

## calibrate

输入：已发布模型、明确版本的数据集、训练与验证划分及校准配置。
输出：新模型版本、使用的数据 ID、校准参数、独立验证指标及适用范围。不得覆盖旧模型和旧预测。

## 验证要求

检查单位、边界、异常输入与已知参考案例；采用按晶圆或批次划分的独立验证，避免同一样品数据泄漏导致高估效果。
